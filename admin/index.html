Connecting ChatVarX Mobile App (Auto-Update Integration)

Your Flutter app can call your website's API endpoint on launch to automatically prompt users when you publish a new APK in this admin panel.

1. Version Check Endpoint:
GET /api/apk/latest
2. Flutter Sample Code Snippet:
// In your ChatVarX Flutter app (e.g., in main.dart or splash screen): Future<void> checkForAppUpdate() async { try { final response = await http.get(Uri.parse('http://your-server-ip:3000/api/apk/latest')); if (response.statusCode == 200) { final data = jsonDecode(response.body); int serverVersionCode = data['versionCode']; int currentAppVersionCode = 4; // Current local app build if (serverVersionCode > currentAppVersionCode) { // Trigger Update Dialog showUpdateDialog( version: data['versionName'], notes: data['releaseNotes'], downloadUrl: data['downloadUrl'], isForce: data['isForceUpdate'] ); } } } catch (e) { print("Update check error: $e"); } }
